# Smart Placement Preparation Platform (Prototype)

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Select a learning module and answer the quiz.
4. Progress is stored in that browser using `localStorage`.

## Files
- `index.html`: page structure
- `style.css`: responsive design
- `script.js`: modules, quizzes, progress and local storage

## Important limitations
This is a front-end prototype for a student project. It has no real login, server, database, teacher account, college integration, or live coding evaluator. Do not enter sensitive personal information. Progress is local to the browser and may be removed if browser data is cleared.

## Suggested next steps
Add a backend and database, secure user authentication, question management, faculty dashboard, accessibility testing, and user feedback before any real deployment.
